4. 위키 실습 — 컨텍스트 엔지니어링

  • 조회: MCP user-mcp-atlassian → confluence_search → confluence_get_page
  • 한 줄 정의: AI에게 넘기기 전 보여줄 정보 환경을 설계하는 일 — 필요한 정보는 context에, 불필요한 정보는 없게 유지
  • 비유: 프롬프트 엔지니어링 = 편지 문장 다듬기 / 컨텍스트 엔지니어링 = 회의실에 필요한 자료만 올려 두기
  • 관계: wiki 기준 Harness ⊇ Context ⊇ Prompt — 하네스(도구·루프) > 컨텍스트 > 프롬프트
  • 참고 wiki: 항상컨텍스트를 생각하며 개발하기, agentic design patterns 요약, Harness 엔지니어링

5-1. Pexels MCP 연동

설정

  • 서버: pexels-mcp-server (Python, PyPI)
  • 실행: uvx pexels-mcp-server (uvx로 자동 설치·실행)
  • API 키: pexels.com/api에서 무료 발급
  • mcp.json 위치: ~/.cursor/mcp.json (글로벌)

활용 도구

도구용도
photos_search키워드로 무료 고화질 사진 검색 (orientation, size, color 필터)
photo_get특정 사진 ID로 상세 정보·URL 조회
videos_search영상 검색 (향후 활용 가능)

워크플로

  1. 슬라이드 주제별 키워드로 photos_search 호출 (landscape, medium)
  2. 결과에서 적합한 사진 선택 → src.landscape URL 추출
  3. Invoke-WebRequest로 images/ 폴더에 다운로드
  4. HTML <img> 태그 src 경로 업데이트

6. 배운 점

  1. Rule은 “항상 켜 둘 것”, Skill은 “이런 요청일 때 읽을 매뉴얼”로 역할을 나눈다.
  2. MCP wiki 조회는 도구 스키마 확인 후 search → get_page 순서가 안정적이다.
  3. 컨텍스트 엔지니어링은 프롬프트 한 줄보다 AI가 보는 전체 맥락 설계가 중요하다.
  4. 모바일 스와이프는 자식 요소(SVG 등)보다 전용 레이어에서 이벤트를 받는 것이 낫다.
  5. 터치·포인터 이벤트를 동시에 쓰면 제스처가 꼬일 수 있어, 역할을 분리하거나 한쪽으로 통일한다.
  6. MCP 서버 연결은 도구 스키마(JSON) 확인 → mcp.json 등록 → Cursor 재시작 순서. uvx로 Python 패키지를 즉시 실행할 수 있다.
  7. 카드뉴스 디자인에서 이미지 + 그라데이션 오버레이 + 텍스트 3레이어 구조가 가독성과 비주얼을 동시에 잡는 핵심 패턴이다.
  8. Pexels 같은 무료 스톡 이미지 MCP를 쓰면 채팅 안에서 이미지 검색·다운로드·적용까지 자동화할 수 있다.
  9. 제출물 파일명은 [날짜][이름]영문제목 형식으로 통일하면 정렬·관리가 편하다.
